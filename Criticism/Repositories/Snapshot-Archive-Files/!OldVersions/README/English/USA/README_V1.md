# Snapshot/archive files

I keep archive (snapshots) of the files I work with, as I like to be able to reference older versions, and revisit them at times. These files are stored in a folder either called `OldVersions` or `!OldVersions` I am told that Git has a feature known as releases, and I do utilize releases, but I am not entirely trusting of the Git system I use, and older files are sometimes necessary to use. It would be extra work to visit old files through tagged releases. I utilize both tags/releases, and snapshot files. I also typically have to create a discussion for each release.

This history of snapshot files goes back all the way to 2018, when I wasn't using Git.

I plan to release build scripts in the future that can target these files and delete them during repository installation, but a method for this is not yet available.
