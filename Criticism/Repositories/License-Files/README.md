# License files

This is my most extensive criticism, yet I don't have a proper fix for it yet.

I keep license files in my repository, most often the GNU General Public License. I keep 2 copies of it, one labeled GPL, and one labeled GPL3. On many repositories, I also keep copies of these 3 copies, with extensions associated with the designated languages of the project. These files are not meant to be opened as programs, documents, or images, they are meant to be opened as plain text. For a Python repository, there are usually 12 for Python, as Python has 4 extensions. Compression can really reduce the size of these.

This is done to indicate the language of the repository in the Git Linguist, and to avoid creating project language files, which take a lot more time and effort to create. These license files may be removed in the future, once the languages of the repository are set up.

License files are something that help mark the projects for me, and it is a useful setup tool. I plan to release build scripts in the future that can target these files and delete them during repository installation, but a method for this is not yet available.
