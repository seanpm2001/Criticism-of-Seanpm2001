# Language switcher

I am sometimes criticized for my language switcher section, which allows readers to switch the language of the `README` file. Since I don't have an automated machine translation method that creates copies of the files in different languages, this section doesn't really do anything in most repositories, as I can't manually translate and create files for all of these repositories. I am also hoping that a different method can succeed this in the future. I try to be as linguistically diverse in my projects as possible, and include support for as many languages as possible.
